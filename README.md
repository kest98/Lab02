ПР2. Ответы на контрольные вопросы
1. Потому что double хранит число в двоичном виде, и некоторые простые десятичные дроби (например 0.1) не могут быть представлены в двоичной системе абсолютно точно, накапливается крошечная погрешность. При работе с деньгами копейка расхождения — уже баг.
2. Значение просто обнулится и превратится в 0.
3. В Python тип меняется на ходу, а в C# тип жестко определяется всего один раз — в момент компиляции. Компилятор сам смотрит на значение справа от знака равно и подставляет нужный тип.
4. Всегда возвращает обычную текстовую строку.
5. Если ввести буквы вместо цифр, int.Parse сразу сломает программу ошибкой. А int.TryParse — это безопасный способ, программа из-за него не упадёт
6. false значит, что перевод текста в число не удался. При этом в переменную out автоматически запишется обычный 0.
7. Его нужно использовать всегда при обычном вводе данных пользователем с клавиатуры, потому что мы никогда не можем быть уверены, что именно введёт человек.
